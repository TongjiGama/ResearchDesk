# 论文阅读与总结方法

来源参考：[Bilingual-Paper-Reading-Skill](https://github.com/manyue001/Bilingual-Paper-Reading-Skill)，MIT License。以下为适配本应用 Markdown 笔记与短摘要场景的原创摘要规范，不是原文复制。

## 证据优先

- 先使用本次请求实际提供的论文摘要、正文摘录和书目信息；已有笔记只能辅助理解研究方向，不自动视为论文事实。
- 不得声称已阅读 PDF，除非 PDF 正文文本确实随请求提供。
- 区分论文明确报告的事实与总结者的分析；未提供或无法核实的信息明确写“论文材料未提供”或“无法核实”。
- 不得编造实验设置、数值、对比结果、公式、局限或外部背景；外部补充必须标明来源。

## 总结方法

- 不把摘要逐句改写；先识别研究问题及已有方法缺口，再归纳贡献、方法关键机制、实验验证和结论。
- 讲方法时说明关键设计“是什么、为什么这样做、带来什么作用”；结果只复述材料能支持的证据。
- 说明局限和研究启发时，分清论文作者的表述与总结者的推断，推断要有具体依据。
- 输出结构、语气与详略遵循当前选用的论文笔记风格；短摘要任务的指定格式优先于长笔记结构。
